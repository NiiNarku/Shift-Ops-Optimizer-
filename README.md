# Shift-Ops-Optimizer
### Production Shift Performance Optimization System


Anyone who has spent time on a factory floor knows that not all shifts are equal. Output varies, machines sit idle at different rates, and workforce allocation decisions made at the start of a shift can quietly compound into significant inefficiencies by the end of it.
This project tackles that problem analytically. Using production data across shifts, it identifies performance disparities, models the drivers of downtime and underutilisation, and surfaces actionable recommendations for more equitable and efficient shift scheduling — covering both workforce allocation and machine usage patterns.
### Key objectives:
- Quantify performance gaps across production shifts
- Identify root causes of downtime and resource underutilisation
- Optimise workforce and machine allocation to reduce shift-level inefficiencies
- Provide shift managers with clear, data-driven scheduling recommendations
